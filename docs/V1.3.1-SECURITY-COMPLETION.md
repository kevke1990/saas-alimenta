# v1.3.1 Security Completion

Deze release maakt de eerder aanwezige security-fundamenten operationeel.

## MFA
TOTP MFA is functioneel via:
- `POST /api/auth/mfa/setup`
- `POST /api/auth/mfa/verify`
- `POST /api/auth/mfa/disable`

De secret wordt AES-256-GCM versleuteld opgeslagen. Bij een ingeschakelde MFA is de TOTP-code verplicht bij login.

## RBAC
Rollen zijn: `PROFESSIONAL`, `PRACTICE_ADMIN`, `ADMIN`. Gebruik `requireRole()` server-side voor iedere nieuwe gevoelige route. `isAdmin` blijft als backwards-compatible legacy flag aanwezig.

## Rate limiting
Login en registratie gebruiken de database-backed `RateLimitBucket`, zodat limieten ook bij meerdere app-containers gedeeld worden. De oude in-memory helper blijft beschikbaar voor laag-risico lokale use-cases.

## Retention
De retention job verwijdert oude documenten, audit logs en verlopen rate-limit buckets conform de standaardretentie. De Debian installer registreert een dagelijkse cron-run om 03:17.

## Passkeys
De bestaande `Passkey` tabel en user flag zijn voorbereid voor WebAuthn. De release blokkeert geen bestaande accounts en vereist voor passkeys een browser/WebAuthn registration ceremony voordat deze als actief kan worden gemarkeerd.
