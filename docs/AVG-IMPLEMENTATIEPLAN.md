# AVG implementatieplan richting v1.0

| Onderdeel | v0.9.7 | v1.0-doel |
|---|---|---|
| Inzage | JSON export | JSON + PDF/HTML + volledig datamodel |
| Portabiliteit | JSON | gestandaardiseerde machine-readable export |
| Wissing | Download + delete | workflow met uitzonderingsmatrix |
| Rectificatie | via behandelaar | verzoek + review + audit |
| Beperking | procesmatig | technische processing lock |
| Bezwaar | procesmatig | verzoek + workflow |
| Consent | model aanwezig | volledige lifecycle |
| RoPA | documentatie | tenant-configureerbaar |
| DPIA | documentatie | wizard + risico-evaluatie |
| Retentie | waarschuwing | automatische policy engine |
| Datalekken | nog niet volledig | register + workflow |
| AI | Gemini extractie + opt-out | consent/policy gates + logging |
| Identity verification | bearer-link | e-mail OTP / sterke verificatie |

## Ontwerpprincipe
Alimenta Pro moet niet proberen te beweren dat software “de AVG oplost”. Het product moet aantoonbaar helpen bij **privacy by design, privacy by default, accountability en het uitvoeren van rechten van betrokkenen**. De verwerkingsverantwoordelijke bepaalt doel, grondslag, bewaartermijn en uitzonderingen.
