# Alimenta Pro v1.3.1 — automatische Debian 13 deployment

## Doel
Een verse Debian 13 server kan vanaf de uitgepakte release automatisch worden ingericht met Docker, PostgreSQL, Nginx, UFW, fail2ban, secrets, Prisma migrations, production build, HTTPS en healthchecks.

## Installatie
1. DNS A/AAAA record naar de server laten wijzen.
2. Upload en pak de v1.3.1 ZIP uit.
3. Voer uit als root:

```bash
cd /pad/naar/Alimenta-Pro-v1.3.1
test -f deploy/installer.sh && bash deploy/installer.sh
```

De installer:
- controleert Debian 13 en amd64/arm64;
- installeert Docker uit de officiële Docker-repository;
- maakt `/opt/alimenta` en een system user;
- genereert secrets en bewaart `.env` met mode 600;
- bouwt de app met Node 22 in Docker;
- voert `prisma migrate deploy` uit;
- publiceert Next.js uitsluitend op `127.0.0.1:3000`;
- configureert Nginx;
- probeert automatisch Let's Encrypt te activeren als DNS werkt;
- controleert `/api/health`.

## Beheer
```bash
alimenta doctor
alimenta status
alimenta logs
alimenta backup
CONFIRM_RESTORE=YES alimenta restore /opt/alimenta/backups/FILE.sql.gz
alimenta update
```

## Update-strategie
`alimenta update` maakt eerst een PostgreSQL-backup, bewaart de vorige app-image, valideert Compose, bouwt de nieuwe image, voert migrations uit, herstart de app en controleert health. Bij een mislukte healthcheck wordt geprobeerd terug te vallen op de vorige image.

## Cloudflare
Voor Cloudflare proxying: gebruik bij voorkeur SSL/TLS **Full (strict)**. De installer gebruikt standaard Let's Encrypt. Een Cloudflare Origin CA-certificaat kan daarna als Nginx-certificaat worden geplaatst; de private key moet root-only blijven.

## Belangrijk
Docker-gepubliceerde poorten kunnen firewallregels omzeilen. Daarom publiceert de compose alleen `127.0.0.1:3000`; PostgreSQL gebruikt uitsluitend het interne Compose-netwerk.

MFA/passkeys, volledig gedistribueerde rate limiting, automatische retention jobs en volledige per-resource RBAC zijn in v1.3.1 nog geen volledig operationele enterprise features; deze blijven expliciet vervolgwerk.
