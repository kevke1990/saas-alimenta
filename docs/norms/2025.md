# NormSet 2025

Source: Rechtspraak / Expertgroep Alimentatienormen, Rapport Alimentatienormen 2025.
Effective: 1 January 2025.

Official sources:
- Rapport Alimentatienormen 2025
- Behoeftetabel 2025
- Draagkrachttabel 2025

Key child-support formula above the table threshold: `70% × [NBI − (0.30 × NBI + €1,310)]` for non-AOW, with the year-specific table below the threshold.

The 2025 need table uses income points from €2,000 through €7,500. Historical calculations must select this table explicitly and must not use 2024/2026 values.
