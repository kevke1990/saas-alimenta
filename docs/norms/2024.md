# NormSet 2024

Source: Rechtspraak / Expertgroep Alimentatienormen, Rapport Alimentatienormen 2024.
Effective: 1 January 2024.

Official sources:
- Rapport Alimentatienormen 2024
- Behoeftetabel 2024
- Draagkrachttabel 2024

Key child-support formula above the table threshold: `70% × [NBI − (0.30 × NBI + €1,270)]` for non-AOW, with the year-specific table below the threshold.

The 2024 need table has income points from €1,500 or less through €6,000 or more. Historical calculations must select this table explicitly and must not use 2025/2026 values.
