# Alimenta Pro v1.3.1 — Hardening & Production Readiness

## Doel
Alle eerder als geel gemarkeerde onderdelen zijn technisch voorbereid: professionele rapportage/status, overrides en audit trail, reviewworkflow, rate limiting, security headers, AVG-retention helpers, Stripe/mail/AI testpunten en MFA/passkey/RBAC-fundament.

## Database
Gebruik op staging eerst:

```bash
npx prisma migrate deploy
npx prisma generate
```

De migratie `20260905103000_v1_3_hardening` voegt reviewstatusvelden, professionele overrides en security-identiteitsvelden toe.

## Testen

```bash
npm ci
npm test
npm run build
```

## Demo smoke test
1. Registreren/inloggen.
2. Dossier aanmaken.
3. KA berekenen en snapshot controleren.
4. PAL berekenen.
5. Scenario maken en verschil controleren.
6. Case Review uitvoeren.
7. Reviewstatus naar REVIEWED → APPROVED → FINAL.
8. Professionele override toevoegen met reden.
9. Rapport genereren en controleren op engine/norm/status/overrides.
10. Stripe test checkout + webhook dubbel aanbieden.
11. Mail verzenden en inbound reply testen.
12. AI-documentanalyse uitvoeren en alleen geaccordeerde feiten toepassen.

## Nog bewust rood
De daadwerkelijke demo-deployment, externe security/penetratietest, onafhankelijke juridische review, formele DPIA/verwerkingsregister, productie-SLA/monitoring en live domein/Stripe/SMTP-inrichting gebeuren pas nadat v1.3 op staging draait.
