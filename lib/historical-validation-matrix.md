# Historical validation matrix

## Global gates

A historical period is executable only when:

- all required parameters are verified;
- the historical rule set is verified;
- official provenance is present;
- reference calculations pass;
- transition/boundary tests pass.

## Required matrix

For every period 2006–2023, test:

- minimum-income case;
- low-NBI case;
- formula-threshold case;
- representative middle-NBI case;
- high-NBI case;
- care-discount boundaries;
- KGB/child-regulation boundaries;
- January/July transitions where applicable;
- 2013 April transition.

## Release rule

No historical period may silently fall back to a current norm set. Any missing source or unresolved reference case blocks historical release readiness.
